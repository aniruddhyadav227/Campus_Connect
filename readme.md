# 🎓 CampusConnect — College Management Portal

A responsive, multi-page student portal built using HTML, CSS, and JavaScript to help students manage their academic activities.

## ✨ Features

- 📊 **Dashboard:** View academic summaries and pending tasks.
- 📅 **Attendance Manager:** Track and update subject-wise attendance.
- 🗓️ **Timetable:** View the weekly class schedule.
- ✅ **Study Planner:** Add, complete, filter, and delete study tasks.
- 📚 **Study Resources:** Save and search useful learning links.
- 👤 **Student Profile:** Manage student details.
- 💾 **Local Storage:** Save supported changes in your browser.
- 📱 **Responsive Design:** Supports desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Browser LocalStorage
- Git and GitHub

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## 📁 Project Structure

- `index.html` — Main dashboard
- `pages/` — Attendance, timetable, planner, resources, and profile pages
- `css/` — Stylesheets
- `js/` — JavaScript functionality
- `data/` — Sample project data
- `assets/` — Images and icons

## 🔒 Important Note

This is a front-end educational project. It uses sample academic data and browser storage. It does not provide secure login, a backend database, or official college records.

**Do not enter sensitive personal information.**
